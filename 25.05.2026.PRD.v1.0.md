## 1. Business Overview

**SheGlow** is a B2C Egyptian e-commerce store selling women's hand accessories and jewellery (bracelets, necklaces, rings, chains, anklets, earrings). Target market: Egyptian women aged 18–40.

- **Currency**: EGP (Egyptian Pounds) — all prices, fees, totals
- **Language**: English UI
- **Geography**: Egypt only — 27 governorates, each with its own shipping fee
- **Business model**: Direct sales with Cash on Delivery as primary payment. Card (PayMob), InstaPay, and Vodafone Cash also supported
- **Contact channels**: WhatsApp floating button, Instagram link, contact form

## 4. Data Models

### 4.1 `accounts.User` (custom auth user)

```python
USERNAME_FIELD = 'phone'
REQUIRED_FIELDS = ['first_name', 'last_name']

phone       = CharField(max_length=20, unique=True)   # primary identifier
email       = EmailField(blank=True, null=True)        # optional
first_name  = CharField (inherited from AbstractUser)
last_name   = CharField (inherited from AbstractUser)
is_active, is_staff, is_superuser  (inherited)
```

- Egyptian phone validation: 11 digits starting with `01`
- `user.full_name` property → `"{first} {last}".strip() or phone`
- `UserManager.create_user(phone, password, **extra_fields)`
- `UserManager.create_superuser(phone, password, **extra_fields)`

### 4.2 `accounts.Customer`

One-to-one with `User`. Stores shipping address defaults.

```python
user        = OneToOneField(User, related_name='customer')
address     = TextField(blank=True)
city        = CharField(max_length=100, blank=True)
governorate = CharField(max_length=50, choices=EGYPTIAN_GOVERNORATES, blank=True)
```

### 4.3 `accounts.Wishlist`

```python
user    = ForeignKey(User, related_name='wishlist')
product = ForeignKey(Product, related_name='wishlisted_by')
added_at = DateTimeField(auto_now_add=True)
# unique_together: (user, product)
```

### 4.4 `products.Category`

```python
name      = CharField(max_length=100)
slug      = SlugField(unique=True)          # auto-generated from name
image     = ImageField(upload_to='categories/', optional)
is_active = BooleanField(default=True)
order     = IntegerField(default=0)          # display order
```

### 4.5 `products.Product`

```python
name        = CharField(max_length=200)
slug        = SlugField(unique=True)          # auto-generated
category    = ForeignKey(Category, null=True, related_name='products')
description = TextField(blank=True)
price       = DecimalField(10,2)             # original price
sale_price  = DecimalField(10,2, optional)   # if set, used as effective price
sku         = CharField(max_length=100, unique=True)  # auto-UUID if blank
stock       = PositiveIntegerField(default=0)
is_active   = BooleanField(default=True)
badge       = CharField choices: '', 'new', 'sale', 'bestseller', 'limited'
created_at, updated_at
```

**Properties**: `effective_price`, `is_on_sale`, `primary_image`, `discount_percentage`

### 4.6 `products.ProductImage`

```python
product    = ForeignKey(Product, related_name='images')
image      = ImageField(upload_to='products/')
alt_text   = CharField(blank=True)
is_primary = BooleanField(default=False)     # only one per product enforced in save()
order      = IntegerField(default=0)
```

### 4.7 `orders.Cart` / `orders.CartItem`

```python
# Cart
user        = OneToOneField(User, null=True, blank=True)
session_key = CharField(max_length=40)       # for guest carts
created_at, updated_at

# CartItem
cart     = ForeignKey(Cart, related_name='items')
product  = ForeignKey(Product)
quantity = PositiveIntegerField(default=1)
# unique_together: (cart, product)
# subtotal property = product.effective_price * quantity
```

Cart is **merged** into user cart on login via `orders.views.merge_carts(user, session_key)`.

### 4.8 `orders.ShippingZone`

```python
governorate  = CharField(max_length=50, unique=True)
shipping_fee = DecimalField(8,2)
delivery_days = PositiveSmallIntegerField(default=3)
is_active    = BooleanField(default=True)
```

27 zones seeded via `python manage.py seed_shipping_zones`. Fee ranges: Cairo/Giza 30 EGP → Remote 70 EGP.

### 4.9 `orders.PromoCode`

```python
code           = CharField(max_length=50, unique=True)   # auto-uppercased
discount_type  = 'percentage' | 'fixed'
discount_value = DecimalField
min_order_amount = DecimalField (optional)
max_uses       = IntegerField (optional)
times_used     = IntegerField(default=0)
is_active      = BooleanField
valid_from, valid_until = DateTimeField
```

**Methods**: `is_valid(order_total)` → `(bool, msg)`, `calculate_discount(subtotal)` → Decimal

### 4.10 `orders.Order`

```python
user          = ForeignKey(User, null=True)  # null for guest orders
order_number  = CharField, unique, auto-generated: 'SG-YYYYMMDD-NNNN'

# Shipping snapshot (copied from form at checkout time)
full_name, email, phone, address, city, governorate

# Financials
subtotal, shipping_fee, discount_amount = DecimalField

# Payment

# Status
```

**`status_steps` property**: returns list of `(step, is_done, label)` for progress bar display.

## 6. Template System

All templates extend `templates/base.html`.

### `base.html` provides:

- `<head>`: Open Graph meta, SVG favicon, Google Fonts (Cormorant Garamond + Inter), Tailwind CDN with custom config, Alpine.js CDN
- **Navbar**: sticky, logo, desktop nav (Home, Shop, Categories dropdown via `{% load_categories %}`), search icon, wishlist badge, cart badge, Login/Create Account (guests) or profile link (authenticated)
- **Live search dropdown**: triggered by search icon, Alpine.js `appState()`, debounced 300ms, calls `/api/search/?q=`, shows results after 4 chars typed, `@keydown.enter` → `/search/?q=`
- **Toast notifications**: `showToast(message, type)` global JS function
- **Footer**: brand, quick links, policy links, WhatsApp + Instagram social icons
- **WhatsApp floating button**: bottom-right, links to `WHATSAPP_NUMBER`
- **Global JS functions**: `addToCart(productId, event)`, `toggleWishlist(productId, btn)`, `getCsrf()`, `updateCartBadge(count)`, `updateWishlistBadge(count)`
- **Alpine.js `appState()`**: `mobileMenuOpen`, `searchOpen`, `searchQuery`, `searchResults`, `searchLoading`, `searchNoResults`, `doSearch()`, `closeSearch()`

### Context Processors (auto-available in all templates):

```python
# sheglow/context_processors.py
site_settings  → WHATSAPP_NUMBER, INSTAGRAM_URL, SITE_NAME, SITE_TAGLINE
cart_count     → cart_count (integer)
wishlist_context → wishlist_ids (set of product IDs), wishlist_count (integer)
```

### Template Tags (`{% load product_tags %}`):

```python
{% load_categories %}          # inclusion tag → nav_categories.html
{% load_categories_mobile %}   # inclusion tag → nav_categories_mobile.html
{{ value|currency }}           # filter → "1,234 EGP"
```

- **Order confirmation**: accessible without login (for guest orders)
- **Promo codes**: percentage or fixed, date validity, usage limit, min order amount

### ✅ Phase 4 — Search, Auth, Shipping, Admin Tools, Analytics

- **4.1 Live search**: AJAX `/api/search/?q=`, Alpine.js dropdown in navbar, debounced 300ms, triggers at 4 chars, Enter → full search page

## 9. Key Conventions & Patterns

### Authentication
- `@login_required` redirects to `LOGIN_URL = '/accounts/login/'`
- `@staff_member_required` (analytics) redirects to `/admin/login/`
- Guest cart merges into user cart on login automatically

### AJAX Pattern
- All AJAX endpoints return `JsonResponse`
- Cart actions send `X-CSRFToken` header; CSRF token read from `getCsrf()` in base.html JS
- Wishlist toggle: POST to `/wishlist/toggle/<id>/`; unauthenticated → `{redirect: '/accounts/login/?next=...'}`

### Cart Behavior
- Authenticated: `Cart.objects.get_or_create(user=request.user)`
- Guest: `Cart.objects.get_or_create(session_key=session_key, user=None)`
- On login: `merge_carts(user, session_key)` — adds guest items to user cart (capped at product stock)

### Checkout Shipping Fee
- `orders.views.get_shipping_fee(governorate)` → queries `ShippingZone`, falls back to `settings.DEFAULT_SHIPPING_FEE`
- On page load: pre-filled from user profile governorate
- Live update: Alpine.js `@change` on governorate select → fetch `/checkout/shipping-fee/?governorate=X` → updates `shippingFee` and `deliveryDays` reactively

### Order Number Format
- `SG-YYYYMMDD-NNNN` (e.g., `SG-20260525-0001`)
- Sequential per day, zero-padded to 4 digits

### PDF Invoice
- ReportLab, A4, rose-branded (`#F43F5E`)
- Served inline (opens in browser tab), filename: `invoice-<order_number>.pdf`
- Accessible to order owner or staff

### Admin Excel Export
- `openpyxl` action on `OrderAdmin`
- Pink header row (`#FFB3C6`)
- Auto-sized columns (capped at 60 chars)
- Filename: `sheglow_orders.xlsx`

### Governorates
- Defined in `accounts/models.py` as `EGYPTIAN_GOVERNORATES` (list of `(value, label)` tuples)
- 27 governorates, values are English names (e.g., `'Cairo'`, `'Giza'`)
- Used as `choices` on `Customer.governorate` and on `Order.governorate`
- `ShippingZone.governorate` values match the same English names

### Product Badges
- Choices: `''` (none), `'new'`, `'sale'`, `'bestseller'`, `'limited'`
- CSS classes: `.badge-new`, `.badge-sale`, `.badge-bestseller`, `.badge-limited`

### Template Loading
- All templates live in `/templates/` (project-level `DIRS`)
- `APP_DIRS = True` so app-level templates also work, but none are used currently

```
accounts/
  0001_initial            ← original User/Customer (email-based)
  0002_…                  ← intermediate (may vary)
  0003_…                  ← Wishlist model
```

## 14. Known Issues & Notes

1. **Search API minimum**: The API returns results for queries ≥ 2 chars; the navbar JS only triggers at 4 chars. Both are intentional (API can be called directly).
2. **Guest order detail**: Guests cannot view `/orders/<num>/` (requires login). They can view `/order/confirmation/<num>/` (no login required).
3. **PayMob**: Integration is complete but disabled by default (`PAYMOB_ENABLED=False`). Enable by setting credentials in `.env`.
4. **Stock reservation**: No soft-reserve during checkout. Race condition on last-item stock is possible.
5. **`DEFAULT_SHIPPING_FEE`**: Used as fallback when a governorate has no `ShippingZone` record or zone is inactive.
6. **Manual order creation in admin**: When staff creates an order manually, stock is decremented once via `save_related`. Re-saving an existing order does NOT decrement again (the `not change` guard).
7. **Analytics non-staff redirect**: Goes to `/admin/login/` (Django's `@staff_member_required` default), not the site login page.
8. **`DjangoJSONEncoder`**: Decimal values in analytics JSON are serialized as strings; JS uses `parseFloat()` to convert.
